# EchoTalking 体验优化任务

## 1. 使用规则

- 任务完成后将标题中的 `[ ]` 改为 `[x]`。
- 只有实现、自动化验证和人工体验验证均满足验收条件时才能勾选。
- 每个任务完成后在标题下增加“完成证据”，包含日期、PR/commit、测试和截图路径。
- 未完成部分必须保留未勾选状态，不以“代码已写”替代端到端验收。

## 2. 全局边界

- 保持 PostgreSQL 为消息、权限、Run 和通知的权威数据源。
- 所有房间、Thread、Artifact 和 Agent 操作必须服务端重新鉴权。
- 不在浏览器、SSE、日志和通知中暴露 Provider/MCP 密钥或工具原始敏感参数。
- 新功能必须兼容现有房间消息和 Agent Run，不要求破坏性数据重建。
- 移动端、键盘操作和屏幕阅读器属于验收范围。
- 不在本阶段实现语音、视频、直播或 Discord 完整服务器体系。
