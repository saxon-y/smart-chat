# Smart Chat

Smart Chat 是一个计划使用 Next.js 构建的多人实时文字聊天室。用户可注册、登录、设置头像与昵称、浏览公开聊天室、创建或加入聊天室，并通过 `@大聪明` 在房间内调用本地 AI 服务。

当前阶段只包含产品与工程规划，不包含业务实现。

## V1 边界

- 仅支持文字消息。
- 房间目录公开；房间消息仅对已加入成员可见。
- 每个房间默认包含系统 AI 成员“大聪明”。
- AI 只在被结构化提及时响应。
- AI 模型厂商配置仅由系统管理员维护，密钥只保存在服务端。
